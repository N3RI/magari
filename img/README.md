# Carpeta de imágenes de productos

Coloca aquí los archivos de imagen para cada producto en formato `.jpg` o `.png`.
Ejemplos de nombres esperados según `js/app.js`:
- `cafe.jpg`
- `latte.jpg`
- `chocotorta.jpg`
- `tostado-magari.jpg`
- `croissant-jyq.jpg`

Si un producto no tiene imagen aún en esta carpeta, el sistema mostrará automáticamente una ilustración elegante con el ícono de su categoría sin romper el diseño.
